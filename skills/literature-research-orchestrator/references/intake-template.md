# Intake Template

Use this template when user asks “帮我调研xxx” and key parameters are missing.

1. 时间窗口是？（例如 2025-01-01 到 2026-02-15）
2. 来源范围是？（例如仅 arXiv + IEEE）
3. 主题关键词与排除关键词是？
4. 目标产物是？（例如 Top10 + 逐篇精读 + 总综述）
5. Zotero 归档到哪个集合？（名称或 key/id）
6. 本地输出根目录放哪里？
7. 输出语言和格式是什么？（中文/英文；md/tex/pdf）
8. 评分方法与权重是什么？（必填）
   - 可直接选模板：影响力优先 / 新颖性优先 / 工程落地优先 / 平衡综合（见 `references/ranking-profiles.md`）
   - 或自定义权重（总和=100）并给并列时排序规则（tie-break）

Do not proceed to retrieval until all required items are answered.
